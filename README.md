# Abhinav Gyawali — Aviation Portfolio

A professional aviation/pilot portfolio website with a radar and flight-route themed interface.

## Project structure

```text
.
├── index.html
├── server.js
├── vercel.json
├── package.json
├── README.md
└── .gitignore
```

## Run locally

Install Node.js 18+ and run:

```bash
npm start
```

Open:

```text
http://localhost:3000
```

## GitHub

Create a new GitHub repository and upload all files in this folder.

## Vercel

Import the GitHub repository into Vercel and deploy.

The included `vercel.json` routes requests through `server.js`.

## Notes

The website content and design are based on the uploaded portfolio HTML. External Google Fonts are loaded by the HTML when the site has internet access.
